# WorkFlow — поддержка без потерь

Демо-интерфейс службы поддержки по макету из Figma: публичные страницы, вход, обзорная панель, список и карточка заявки, профиль оператора. Всё работает на локальных mock-данных, без бэкенда.

## Стек

- **Nuxt 4** (SSR), Vue 3, TypeScript
- **Tailwind CSS 4** (`@tailwindcss/vite`)
- Шрифт Montserrat (self-hosted через `@fontsource-variable/montserrat`)
- Дизайн-токены макета — CSS-переменные `--octagon-*` в `app/assets/css/main.css`
- Состояние — `useState`, авторизация — cookie

## Запуск

```bash
pnpm install
pnpm dev
```

Приложение откроется на `http://localhost:3000`.

Проверка типов и production-сборка:

```bash
pnpm typecheck
pnpm build
pnpm preview
```

## Демо-вход

В демо-режиме пользователь уже авторизован как **Анна Ковалёва, оператор**, поэтому `/dashboard`, `/requests` и `/profile` доступны сразу.

Чтобы проверить страницу входа:

1. Выйдите через меню пользователя или кнопку в профиле.
2. Откроется `/login`; введите любой корректный e-mail и пароль от 4 символов.
3. После входа произойдёт возврат на защищённую страницу из параметра `redirect`.

Регистрация в демо не реализована — показывается поясняющее сообщение.

## Маршруты

| Путь | Описание |
| --- | --- |
| `/` | Лендинг: hero с графикой Octagon, 3 шага, возможности, FAQ |
| `/login` | Вход с валидацией и показом пароля |
| `/dashboard` | Обзор: 4 показателя и последние заявки |
| `/requests` | Список заявок: поиск, фильтры, сортировка, пагинация |
| `/requests/:id` | Карточка заявки: описание, комментарии, история, параметры |
| `/profile` | Профиль: данные, настройки интерфейса, выход |

## Возможности

### Список заявок

- 26 mock-заявок, по 12 на страницу.
- Поиск по номеру, теме, клиенту и исполнителю.
- Фильтры по статусу и приоритету, фильтр по исполнителю, сортировка.
- Все параметры синхронизируются с URL: `q`, `status`, `priority`, `assignee`, `sort`, `page`. Ссылкой можно поделиться.
- Отдельные состояния: загрузка, пустой список, ошибка, «ничего не найдено».
- Кнопка сброса фильтров и переход в карточку по клику на строку или карточку.

### Заявка

- Статус, приоритет, клиент, категория, SLA и признак просрочки.
- История событий (создание, назначение, смена статуса, комментарии).
- Добавление комментария, смена статуса и исполнителя — изменения сразу отражаются в истории.
- Состояния загрузки и ошибки, отдельный экран «заявка не найдена».
- Создание новой заявки через модальное окно с валидацией; новая заявка получает следующий номер и открывается сразу.

### Профиль

- Редактирование имени и e-mail с сохранением в cookie и обновлением инициалов.
- Настройка плотности списка и выход из аккаунта.

## Демо-состояния

На странице `/requests` внизу есть переключатель сценария. Те же состояния можно открыть напрямую:

- `/requests?state=loading` — скелетон загрузки;
- `/requests?state=empty` — пустой список;
- `/requests?state=error` — ошибка с кнопкой «Повторить»;
- `/requests/1042?state=loading` и `?state=error` — состояния карточки заявки.

Параметр `state` не мешает фильтрам и сохраняется при переключении страниц пагинации.

## Доступность и адаптивность

- Skip-link к основному содержимому на всех страницах.
- Мобильное меню: focus trap, закрытие по `Esc`, возврат фокуса, навигация стрелками.
- Кастомные селекты: `role="combobox"`/`listbox`, управление стрелками, `Home`/`End`, `Enter`, `Esc`.
- Модальное окно: focus trap, `Esc`, блокировка прокрутки, возврат фокуса.
- Меню пользователя: навигация стрелками, `Home`/`End`, закрытие по `Esc` и клику вне.
- Видимые focus-состояния у кнопок, ссылок, полей и переключателей.
- Поддержка `prefers-reduced-motion`.
- Проверенная вёрстка на 360, 768 и 1280 px: на мобильных таблица заменяется карточками, меню — drawer'ом.

## Структура проекта

```text
app/
  assets/css/main.css        дизайн-токены макета (--octagon-*), тема, анимации
  components/                UI-компоненты и блоки страниц
  composables/               auth, mock-состояния, store заявок, focus trap
  layouts/                   default (app) и public (лендинг/вход)
  middleware/auth.global.ts  защита приватных маршрутов
  pages/                     страницы приложения
  types/                     доменные типы
  utils/                     mock-данные, фильтрация, сортировка, форматирование
  error.vue                  кастомная страница 404/500
public/images/               графика из макета (octagon-hero.png)
nuxt.config.ts               шрифты, head, transitions, tailwind vite-плагин
```

## Ограничения демо

- Данные хранятся в памяти вкладки: изменения статусов, комментарии и новые заявки сбрасываются после полной перезагрузки страницы.
- Авторизация имитируется cookie, реального API нет.
- Уведомления и загрузка файлов не отправляются на сервер.
