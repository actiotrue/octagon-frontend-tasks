UI и компонентное мышление
Создать первую работающую версию WorkFlow на локальных данных и выстроить устойчивую основу интерфейса.
Задачи уровня
Задание №1. UI и компонентное мышление
Не сдана на проверку

Описание

На первом этапе приложение работает без реального backend. Нужно собрать основные страницы WorkFlow, показать список заявок и детали заявки, а также заложить компонентную структуру, которую можно расширять на следующих уровнях.





Необходимо реализовать

создать проект на Nuxt 4 и базовую структуру приложения;
сделать общий layout приложения и отдельный публичный layout;
реализовать страницы /, /login, /dashboard, /requests, /requests/:id и /profile;
создать список минимум из 12 заявок на локальных данных;
создать страницу деталей заявки с timeline и комментариями;
добавить фильтрацию заявок по статусу и приоритету;
сделать отдельные переиспользуемые компоненты для списков и карточек;
реализовать loading, empty и error состояния хотя бы для одного mock-сценария;
добавить базовую навигацию с клавиатуры для меню, фильтров и модального окна;
обеспечить корректное отображение интерфейса на мобильной, планшетной и desktop-ширине.




Требования

Nuxt 4;
для скриптов .vue использовать <script setup lang="ts">. Для остальных скриптов (utils, composables и т. д.) — TypeScript;
локальные mock-данные без обязательного backend;
отдельные переиспользуемые компоненты вместо копирования разметки;
понятные состояния hover, focus и disabled для основных интерактивных элементов;
корректная работа интерфейса на ширине 360px, 768px и 1280px.
